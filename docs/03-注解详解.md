# 注解详解

## 一、Lombok 注解（自动生成代码，减少重复）

### `@Data`
自动生成：getter、setter、toString、equals、hashCode。
```java
@Data
public class Employee {
    private Long id;
    private String username;
    // 不用手写 getId() setId() 等方法
}
```

### `@Builder`
让你用链式写法构建对象，不用一个个 set：
```java
// 没有 @Builder 的写法
EmployeeLoginVO vo = new EmployeeLoginVO();
vo.setId(1L);
vo.setUserName("admin");
vo.setToken("xxx");

// 有 @Builder 的写法（代码里就是这样用的）
EmployeeLoginVO vo = EmployeeLoginVO.builder()
        .id(employee.getId())
        .userName(employee.getUsername())
        .token(token)
        .build();
```

### `@NoArgsConstructor` / `@AllArgsConstructor`
- `@NoArgsConstructor`：生成无参构造方法 `new Employee()`
- `@AllArgsConstructor`：生成全参构造方法 `new Employee(id, username, ...)`

`@Builder` 需要配合这两个一起用，否则 Jackson（JSON 解析）反序列化会报错。

### `@Slf4j`
自动注入日志对象 `log`，不用手写：
```java
// 没有 @Slf4j 要这样写
private static final Logger log = LoggerFactory.getLogger(EmployeeController.class);

// 有 @Slf4j 直接用
log.info("员工登录：{}", employeeLoginDTO);
```

## 二、Spring 核心注解

### `@SpringBootApplication`
启动类上的注解，等于三个注解合一：
- `@SpringBootConfiguration`：标记这是配置类
- `@EnableAutoConfiguration`：开启自动配置（Spring Boot 的核心魔法）
- `@ComponentScan`：扫描当前包及子包下所有 `@Component`、`@Service`、`@Controller` 等

### `@EnableTransactionManagement`
开启注解式事务管理，之后可以在方法上用 `@Transactional`。

### `@RestController`
等于 `@Controller` + `@ResponseBody`。
- `@Controller`：标记这是控制器，Spring 会管理它
- `@ResponseBody`：方法返回值直接写入响应体（转成 JSON），不跳转页面

### `@RequestMapping("/admin/employee")`
类上的注解，定义这个 Controller 的基础路径。

### `@PostMapping("/login")`
处理 POST 请求，完整路径 = 类上的路径 + 方法上的路径 = `/admin/employee/login`。

### `@RequestBody`
把请求体的 JSON 自动转成 Java 对象：
```java
// 前端发来：{"username":"admin","password":"123456"}
// @RequestBody 自动把它转成 EmployeeLoginDTO 对象
public Result<EmployeeLoginVO> login(@RequestBody EmployeeLoginDTO employeeLoginDTO)
```

### `@Autowired`
自动注入依赖，Spring 帮你 new 对象并赋值，不用手动 `new`：
```java
@Autowired
private EmployeeService employeeService;  // Spring 自动注入实现类
```

### `@Service`
标记这是业务层组件，Spring 会扫描到并管理它。

### `@Component`
通用组件标记，`@Service`、`@Controller`、`@Repository` 都是它的特化版本。

### `@Configuration`
标记这是配置类，里面的 `@Bean` 方法会被 Spring 执行并把返回值注册为 Bean。

### `@Bean`
在配置类里用，把方法返回的对象注册到 Spring 容器：
```java
@Bean
public Docket docket() {
    // 返回的 Docket 对象被 Spring 管理
    return new Docket(...);
}
```

## 三、MyBatis 注解

### `@Mapper`
标记这是 MyBatis 的 Mapper 接口，Spring Boot 会自动为它生成实现类（代理对象）。

### `@Select`
直接在方法上写 SQL，不用写 XML：
```java
@Select("select * from employee where username = #{username}")
Employee getByUsername(String username);
// #{username} 是占位符，对应方法参数名
```

## 四、配置属性注解

### `@ConfigurationProperties(prefix = "sky.jwt")`
把配置文件里的值自动绑定到类的字段上：

`application.yml` 里：
```yaml
sky:
  jwt:
    admin-secret-key: itcast
    admin-ttl: 7200000
    admin-token-name: token
```

`JwtProperties.java` 里：
```java
@ConfigurationProperties(prefix = "sky.jwt")
public class JwtProperties {
    private String adminSecretKey;  // 对应 admin-secret-key（短横线转驼峰）
    private long adminTtl;          // 对应 admin-ttl
    private String adminTokenName;  // 对应 admin-token-name
}
```

### `@Component` + `@ConfigurationProperties`
`@Component` 让 Spring 管理这个类，`@ConfigurationProperties` 负责绑定配置值，两个一起用才能生效。

## 五、异常处理注解

### `@RestControllerAdvice`
全局异常处理器标记，拦截所有 Controller 抛出的异常。等于 `@ControllerAdvice` + `@ResponseBody`。

### `@ExceptionHandler`
指定处理哪种异常：
```java
@ExceptionHandler
public Result exceptionHandler(BaseException ex) {
    // 只要任何 Controller 抛出 BaseException（或其子类），就会被这里捕获
    return Result.error(ex.getMessage());
}
```

## 六、Swagger/Knife4j 注解（API 文档）

### `@ApiModel(description = "...")`
给类加描述，显示在接口文档里：
```java
@ApiModel(description = "员工登录时传递的数据模型")
public class EmployeeLoginDTO { ... }
```

### `@ApiModelProperty("...")`
给字段加描述：
```java
@ApiModelProperty("用户名")
private String username;
```

访问 `http://localhost:8080/doc.html` 可以看到自动生成的接口文档。
