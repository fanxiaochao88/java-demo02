这个目录不是原教程的重复，而是给“复习”和“回顾”准备的索引。
建议按“先总览、再链路、再技术点、最后看优化建议”的顺序阅读。

## 这套复习文档解决什么问题

- 帮你从“看过代码”变成“能讲清楚代码”
- 帮你把架构、技术栈、语法、业务链路串成一张图
- 帮你把常见面试/复盘问题提前整理出来
- 帮你看清哪些地方只是能跑，哪些地方值得优化

## 复习方法

1. 先把 `01` 到 `05` 读一遍，建立整体地图。
2. 再看 `06`，把项目里常见语法补齐。
3. 看 `07`，知道哪些地方值得改，为什么改。
4. 最后用 `08` 做问答自测，检查自己能不能独立复述。
5. 复习时别只看结论，尽量自己把“请求进来以后怎么走”复述出来。
