# 02 - 技术栈与配置

## 1. 技术栈清单

| 技术 | 用途 | 项目中的位置 |
|---|---|---|
| Spring Boot 2.7.3 | 启动、自动配置、整合各组件 | `SkyApplication`、`application.yml` |
| Spring MVC | Controller、参数绑定、拦截器 | `WebMvcConfiguration`、各 Controller |
| MyBatis | SQL 映射 | `mapper/*.xml`、各 `Mapper` 接口 |
| MySQL | 持久化存储 | 员工、用户、订单、菜品等表 |
| Druid | 数据源连接池 | `application.yml` |
| PageHelper | 分页查询 | `EmployeeServiceImpl`、`OrderServiceImpl` |
| Redis | 缓存、热点数据 | `RedisConfiguration`、缓存相关 Service |
| Spring Cache | 注解式缓存 | `@EnableCaching` |
| JWT | 登录鉴权 | `JwtUtil`、两个拦截器 |
| Knife4j / Swagger | 接口文档 | `WebMvcConfiguration` |
| Lombok | 减少样板代码 | `@Data`、`@Builder`、`@Slf4j` |
| Fastjson | JSON 解析和序列化 | 微信登录、WebSocket 消息 |
| WebSocket | 实时通知 | `WebSocketServer`、`MyTask`、`OrderServiceImpl` |
| POI | 导出 Excel | `ReportServiceImpl` |
| Tencent COS | 文件上传 | `CommonServiceImpl`、`CosConfig` |
| HttpClient | 调微信接口 | `HttpClientUtil` |

## 2. 启动类里做了什么

`SkyApplication` 不只是启动：

- `@SpringBootApplication`：开启 Spring Boot 自动配置
- `@EnableTransactionManagement`：开启事务
- `@EnableCaching`：开启缓存能力
- `@EnableScheduling`：开启定时任务

```java
@SpringBootApplication
@EnableTransactionManagement
@EnableCaching
@EnableScheduling
public class SkyApplication {
    public static void main(String[] args) {
        SpringApplication.run(SkyApplication.class, args);
    }
}
```

## 3. 配置文件怎么读

`application.yml` 里最值得记的是三类配置：

### 3.1 数据库和 Redis

```yaml
spring:
  datasource:
    druid:
      url: jdbc:mysql://${sky.datasource.host}:${sky.datasource.port}/${sky.datasource.database}
  redis:
    host: ${sky.redis.host}
```

### 3.2 MyBatis

```yaml
mybatis:
  mapper-locations: classpath:mapper/*.xml
  type-aliases-package: com.sky.entity
  configuration:
    map-underscore-to-camel-case: true
```

### 3.3 JWT 和第三方服务

```yaml
sky:
  jwt:
    admin-secret-key: itcast
    admin-ttl: 7200000
    admin-token-name: token
    user-secret-key: itheima
    user-token-name: authentication
```

## 4. 配置绑定的语法

项目用了 `@ConfigurationProperties` 把 yml 映射到 Java 对象：

```java
@Component
@ConfigurationProperties(prefix = "sky.jwt")
@Data
public class JwtProperties {
    private String adminSecretKey;
    private long adminTtl;
    private String adminTokenName;
}
```

这种写法的好处：

- 配置集中管理
- 代码里不用写一堆 `@Value`
- 修改配置不需要改业务逻辑

## 5. 你要重点记住的几个配置类

- `JwtProperties`：管理员和用户 token 配置
- `WeChatProperties`：微信登录参数
- `AliOssProperties`：阿里云 OSS 参数
- `CosConfig`：腾讯 COS 参数

### 注意

项目里真正的文件上传实现走的是 **Tencent COS**，`sky-common` 里的 `AliOssUtil` 更像是另一个云存储实现或历史遗留代码。复习时要知道这两套不是一条主线。

## 6. 技术栈里最容易混淆的点

- **Spring Boot** 负责启动和整合，不等于业务逻辑
- **Spring MVC** 负责 Web 请求，不等于数据库操作
- **MyBatis** 负责 SQL，不负责业务拼装
- **Redis** 是缓存，不是数据库替代品
- **JWT** 只是令牌，不是登录业务本身
