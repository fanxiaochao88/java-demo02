# 04 - 公共基础设施详解

## 1. 统一返回值 `Result<T>`

项目里所有接口尽量都返回 `Result`，这样前端处理简单，接口风格统一。

```java
public class Result<T> implements Serializable {
    private Integer code;
    private String msg;
    private T data;
}
```

### 常用写法

```java
return Result.success();
return Result.success(data);
return Result.error("用户名已存在");
```

### 记忆点

- `code = 1` 表示成功
- `code = 0` 表示失败
- `data` 是泛型，可以装任意对象

## 2. 全局异常处理

项目用 `@RestControllerAdvice` 统一兜底异常。

```java
@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler
    public Result exceptionHandler(BaseException ex) {
        return Result.error(ex.getMessage());
    }
}
```

### 业务异常怎么用

- 业务上可预期的问题，直接抛自定义异常
- 例如：账号不存在、密码错误、购物车为空、地址不存在
- 好处是 Controller 不会被一堆 `if` 和 `try-catch` 弄乱

### 数据库异常怎么兜底

```java
@ExceptionHandler
public Result exceptionHandler(SQLIntegrityConstraintViolationException ex) {
    String message = ex.getMessage();
    if (message.contains("Duplicate entry")) {
        String username = message.split(" ")[2];
        return Result.error(username + "已存在");
    }
    return Result.error("数据库未知异常");
}
```

## 3. 自定义注解 `@AutoFill`

这个注解和 AOP 配合，用来自动填充公共字段。

```java
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface AutoFill {
    OperationType value();
}
```

### 用法

```java
@AutoFill(OperationType.INSERT)
void insert(Dish dish);
```

## 4. AOP 自动填充

`AutoFillAspect` 会拦截 Mapper 方法，自动给实体设置时间和用户 id。

### 核心逻辑

1. 从注解里拿到操作类型
2. 从参数里拿到实体对象
3. 取当前时间和当前用户 id
4. 反射调用 `setCreateTime`、`setUpdateTime` 等方法

### 典型代码

```java
@Pointcut("execution(* com.sky.mapper.*.*(..)) && @annotation(com.sky.annotation.AutoFill)")
public void autoFillPointCut() {}

@Before("autoFillPointCut()")
public void autoFill(JoinPoint joinPoint) throws Exception {
    MethodSignature signature = (MethodSignature) joinPoint.getSignature();
    OperationType value = signature.getMethod().getAnnotation(AutoFill.class).value();
    Object entry = joinPoint.getArgs()[0];
    Method setUpdateTime = entry.getClass().getDeclaredMethod("setUpdateTime", LocalDateTime.class);
    setUpdateTime.invoke(entry, LocalDateTime.now());
}
```

## 5. 反射在这里怎么用

反射不是“为了高级而高级”，它的作用是：

- 不写死实体类类型
- 通过方法名动态调用 setter
- 自动给不同实体统一填公共字段

### 对应风险

- 方法名写错会在运行时才报错
- 反射性能不如直接调用
- 后续如果字段名变了，要同步改常量

## 6. `ThreadLocal` 的正确打开方式

`ThreadLocal` 在这里就是“当前请求专属的小盒子”。

```java
BaseContext.setCurrentId(empId);
Long currentId = BaseContext.getCurrentId();
BaseContext.removeCurrentId();
```

### 为什么一定要 remove

- Web 容器线程会复用
- 不清理会把上一个请求的数据带到下一个请求
- 这是典型的线程污染问题

## 7. 这几个基础设施是整项目的骨架

- `Result` 负责输出风格统一
- 异常处理负责错误统一
- `AutoFill` + AOP 负责公共字段统一
- `ThreadLocal` 负责当前用户统一
