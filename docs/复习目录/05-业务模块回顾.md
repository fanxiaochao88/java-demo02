## 3. 订单状态机要记住

`Orders` 里定义了核心状态：

```java
PENDING_PAYMENT = 1;     // 待付款
TO_BE_CONFIRMED = 2;      // 待接单
CONFIRMED = 3;            // 已接单
DELIVERY_IN_PROGRESS = 4; // 派送中
COMPLETED = 5;            // 已完成
CANCELLED = 6;            // 已取消
```

### 订单流转主线

```text
待付款 -> 待接单 -> 已接单 -> 派送中 -> 已完成
             └-----------------------> 已取消
```

### 关键业务规则

- 待付款、待接单阶段可以取消
- 待接单取消时要处理退款状态
- 超过待接单阶段，取消要受限制

## 4. 三条最重要的业务链路

### 4.1 下单链路

```text
购物车 -> 提交订单 -> 生成订单和明细 -> 清空购物车 -> 返回订单信息
```

### 4.2 支付链路

```text
支付请求 -> 修改订单状态 -> WebSocket 推送新订单通知
```

### 4.3 报表链路

```text
数据库聚合查询 -> DTO -> VO -> ECharts / Excel
```

## 5. 用到的典型编程模式

- `BeanUtils.copyProperties(...)`：对象属性拷贝
- `PageHelper.startPage(...)`：分页
- `stream().map(...).collect(...)`：集合转换
- `OrderDetail` 和 `OrderVO` 组装：一对多数据拼装
- `WebSocket` 推送：把后端事件变成实时消息
