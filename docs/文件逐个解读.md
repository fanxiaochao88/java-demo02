# 每个文件逐个解读

## sky-common 模块

### SkyApplication.java
```
sky-server/src/main/java/com/sky/SkyApplication.java
```
整个项目的入口，`main` 方法在这里。

```java
@SpringBootApplication          // 启动 Spring Boot，自动配置一切
@EnableTransactionManagement    // 开启 @Transactional 注解支持
@Slf4j                          // 注入 log 对象
public class SkyApplication {
    public static void main(String[] args) {
        SpringApplication.run(SkyApplication.class, args);
        log.info("server started");  // 启动成功后打印日志
    }
}
```

### constant/ 常量类

**AutoFillConstant.java** — 自动填充字段的方法名常量
```java
// 后面学 AOP 自动填充时会用到，存的是 setter 方法名字符串
public static final String SET_CREATE_TIME = "setCreateTime";
public static final String SET_UPDATE_TIME = "setUpdateTime";
public static final String SET_CREATE_USER = "setCreateUser";
public static final String SET_UPDATE_USER = "setUpdateUser";
```

**JwtClaimsConstant.java** — JWT 载荷里的 key 名称
```java
public static final String EMP_ID = "empId";    // 员工ID的key
public static final String USER_ID = "userId";  // 用户ID的key
```
用法：`claims.put(JwtClaimsConstant.EMP_ID, employee.getId())`

**MessageConstant.java** — 所有错误提示文字
把字符串集中管理，改一处全改，不会出现拼写不一致的问题。

**PasswordConstant.java** — 默认密码 `123456`

**StatusConstant.java** — 启用/禁用状态
```java
public static final Integer ENABLE = 1;   // 启用
public static final Integer DISABLE = 0;  // 禁用
```
用法：`if (employee.getStatus() == StatusConstant.DISABLE)`

### context/BaseContext.java
```
sky-common/src/main/java/com/sky/context/BaseContext.java
```
用 ThreadLocal 在同一个请求的线程内传递当前用户 ID，避免层层传参。

```java
public class BaseContext {
    public static ThreadLocal<Long> threadLocal = new ThreadLocal<>();

    public static void setCurrentId(Long id) { threadLocal.set(id); }
    public static Long getCurrentId() { return threadLocal.get(); }
    public static void removeCurrentId() { threadLocal.remove(); }  // 防内存泄漏
}
```

### enumeration/OperationType.java
```java
public enum OperationType {
    UPDATE,  // 更新操作
    INSERT   // 插入操作
}
```
后面 AOP 自动填充时，用这个枚举区分是新增还是修改（新增要填 createTime，修改只填 updateTime）。

### exception/ 异常类

**BaseException.java** — 所有业务异常的父类，继承 `RuntimeException`（运行时异常，不需要 try-catch）

其余异常类都是空的，只继承 BaseException：
```java
public class AccountNotFoundException extends BaseException {
    public AccountNotFoundException(String msg) { super(msg); }
}
```
为什么要这么多空类？为了**语义清晰**，看到类名就知道是什么错误，也可以针对不同异常做不同处理。

### result/Result.java
```
sky-common/src/main/java/com/sky/result/Result.java
```
所有接口的统一返回格式。

```java
@Data
public class Result<T> implements Serializable {
    private Integer code;  // 1=成功，0=失败
    private String msg;    // 失败时的错误信息
    private T data;        // 成功时的数据

    // 静态工厂方法，不用 new
    public static <T> Result<T> success(T object) { ... }
    public static <T> Result<T> error(String msg) { ... }
}
```

`implements Serializable` — 表示这个类可以被序列化（转成字节流），网络传输需要。

---

### result/PageResult.java
分页查询的统一返回格式：
```java
public class PageResult implements Serializable {
    private long total;    // 总记录数（用于前端显示"共X条"）
    private List records;  // 当前页的数据列表
}
```

---

### json/JacksonObjectMapper.java
自定义 JSON 序列化规则，解决 `LocalDateTime` 格式问题。

继承 `ObjectMapper`（Jackson 的核心类），在构造方法里注册自定义规则：
- `LocalDateTime` ↔ `"yyyy-MM-dd HH:mm"`
- `LocalDate` ↔ `"yyyy-MM-dd"`
- `LocalTime` ↔ `"HH:mm:ss"`
- 遇到未知字段不报错（`FAIL_ON_UNKNOWN_PROPERTIES = false`）

## sky-pojo 模块

### dto/ 数据传输对象

前端 → 后端传数据用的，只包含前端会传的字段。

**EmployeeLoginDTO.java**
```java
@Data
@ApiModel(description = "员工登录时传递的数据模型")
public class EmployeeLoginDTO implements Serializable {
    @ApiModelProperty("用户名")
    private String username;
    @ApiModelProperty("密码")
    private String password;
}
```

其他 DTO 类似，比如 `EmployeePageQueryDTO` 包含分页参数（page、pageSize）和查询条件（name）。

---

### entity/ 实体类

和数据库表一一对应。

**Employee.java** — 对应 `employee` 表
```java
@Data
@Builder
@NoArgsConstructor
@AllArgsConstructor
public class Employee implements Serializable {
    private Long id;
    private String username;
    private String name;
    private String password;
    private String phone;
    private String sex;
    private String idNumber;      // 身份证号
    private Integer status;       // 1启用 0禁用
    private LocalDateTime createTime;
    private LocalDateTime updateTime;
    private Long createUser;      // 创建人ID
    private Long updateUser;      // 最后修改人ID
}
```

注意 `createTime` 用的是 `LocalDateTime`（Java 8 新日期类），不是老的 `Date`。

---

### vo/ 视图对象

后端 → 前端返回数据用的，只包含前端需要的字段。

**EmployeeLoginVO.java** — 登录成功后返回给前端
```java
@Data
@Builder
@NoArgsConstructor
@AllArgsConstructor
@ApiModel(description = "员工登录返回的数据格式")
public class EmployeeLoginVO implements Serializable {
    private Long id;
    private String userName;
    private String name;
    private String token;   // JWT 令牌，没有 password！
}
```

## sky-server 模块

### config/WebMvcConfiguration.java
Web 层的总配置类，继承 `WebMvcConfigurationSupport`（Spring MVC 配置基类）。

做了三件事：
1. **注册拦截器**：JWT 拦截器拦截 `/admin/**`，排除登录接口
2. **配置 Knife4j**：生成接口文档，扫描 `com.sky.controller` 包
3. **配置静态资源**：让 `/doc.html` 能访问到 Knife4j 的页面文件

---

### interceptor/JwtTokenAdminInterceptor.java
JWT 令牌校验拦截器，实现 `HandlerInterceptor` 接口。

关键判断：
```java
if (!(handler instanceof HandlerMethod)) {
    return true;  // 不是 Controller 方法（如静态资源），直接放行
}
```
这行很重要，否则访问 `/doc.html` 也会被拦截。

---

### handler/GlobalExceptionHandler.java
全局异常处理，`@RestControllerAdvice` 让它能拦截所有 Controller 的异常。

```java
@ExceptionHandler
public Result exceptionHandler(BaseException ex) {
    log.error("异常信息：{}", ex.getMessage());
    return Result.error(ex.getMessage());
}
```

---

### mapper/EmployeeMapper.java
MyBatis Mapper 接口，`@Mapper` 让 Spring Boot 自动生成实现。

```java
@Mapper
public interface EmployeeMapper {
    @Select("select * from employee where username = #{username}")
    Employee getByUsername(String username);
}
```

MyBatis 会把查询结果自动映射到 `Employee` 对象（字段名下划线转驼峰，由 `map-underscore-to-camel-case: true` 配置）。

---

### service/EmployeeService.java
接口，只定义方法签名，不写实现：
```java
public interface EmployeeService {
    Employee login(EmployeeLoginDTO employeeLoginDTO);
}
```

### service/impl/EmployeeServiceImpl.java
实现类，`@Service` 让 Spring 管理，`implements EmployeeService` 实现接口。

登录逻辑：
1. 根据用户名查数据库
2. 用户不存在 → 抛 `AccountNotFoundException`
3. 密码不对 → 抛 `PasswordErrorException`（注意：当前代码注释掉了 MD5，直接比对明文）
4. 账号被禁用 → 抛 `AccountLockedException`
5. 全部通过 → 返回 Employee 对象

---

### controller/admin/EmployeeController.java
员工管理 Controller，处理 `/admin/employee` 路径下的请求。

**登录接口** `POST /admin/employee/login`：
1. 调用 Service 验证登录
2. 生成 JWT token（把员工 ID 放进 token）
3. 用 Builder 构建 VO
4. 返回 `Result.success(vo)`

**退出接口** `POST /admin/employee/logout`：
直接返回成功（JWT 是无状态的，服务端不存 token，退出只需前端删除 token 即可）。

## 配置文件

### application.yml
主配置文件：
- 端口：8080
- 激活 dev 环境（`spring.profiles.active: dev`）
- 数据库连接（引用 dev 配置里的变量）
- MyBatis 配置（Mapper XML 位置、驼峰命名）
- 日志级别（mapper 层 debug，可以看到 SQL）
- JWT 配置

### application-dev.yml
开发环境的数据库连接信息（host、port、database、username、password）。

生产环境会有 `application-prod.yml`，里面是真实服务器的数据库地址。
